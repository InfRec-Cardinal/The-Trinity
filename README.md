## Overview

**The Trinity** is a recursive self-improvement framework that couples world generation with agent Harness evolution. It organizes heterogeneous multimodal tasks by shared capability requirements and connects three roles through verified execution feedback:

- **Creator** builds simplified, verifiable worlds for capability learning.
- **Explorer** interacts with worlds and evolves reusable capability modules through selective inheritance.
- **Evolver** reorganizes task requirements into a hierarchical capability tree.

**Capability-Driven Real2Sim2Real** connects learning in generated worlds with evaluation on original tasks. A **Capability-Aware Harness Router** selects compatible module configurations for each task.

## Highlights

The technical report reports mean performance gains of **34 points across 28 training benchmarks** and **26 points across 18 unseen benchmarks**, including two real-world embodied tasks.
